## ⚡ The 4 "Instant Recognition" Cheat Codes

1. **Value Substitution ($n / \theta$ Method):**
   * If options contain variables ($n, \theta, a, b$), substitute extreme integers ($n=1, 2$) or angles ($\theta = 0^\circ, 45^\circ$) to compute output and eliminate 3 wrong options in 15 seconds.
2. **Odd/Even Annihilation ($\int_{-\alpha}^\alpha$):**
   * Any odd component ($x^3, x\cos x, \sin^5 x$) within symmetric limits instantly integrates to $0$. Discard them immediately.
3. **Fixed Standard Invariants:**
   * Orthogonal matrix: $\det(A) = \pm 1$.
   * Perpendicular tangents locus: Director Circle ($x^2+y^2=a^2+b^2$).
   * If $T_p = 1/q$ and $T_q = 1/p$ in an AP $\implies T_{pq} = 1$.
   * $\int_0^{\pi/2} \frac{\sin^n x}{\sin^n x + \cos^n x} dx = \frac{\pi}{4}$ for any power $n$.
4. **Boundary & Dimensional Elimination:**
   * Probabilities $>1$ or $<0$ are immediately rejected.
   * Variance has **shift-invariance**: adding/subtracting a constant leaves variance and standard deviation completely unchanged ($\text{Var}(X + c) = \text{Var}(X)$).
